\section*{Purpose}
This report describes the actual method stacks selected by the hybrid pruning experiment.  The generic label used in some plots is avoided in the interpretation because it hides the scientific object of interest: the stack itself.  Each result below is therefore reported as a named stack, for example \stackname{S9-global-r0.3}, and compared with the singular methods used as baselines.

\section*{Main conclusion}
The most useful stack in this run is \stackname{S9-global-r0.3}, evaluated at pruning ratio $0.3$.  Across correlation thresholds $0.55$--$0.90$, this same nine-method stack preserves or improves accuracy relative to the baseline while requiring much less reported prune+heal time than any singular method.  The strongest setting is $r=0.3$, correlation threshold $0.90$: healed accuracy is $87.70\%$ ($+9.96$ percentage points versus baseline), FLOPs reduction is $24.81\%$, parameter reduction is $51.79\%$, and reported prune+heal time is $1.23$s.

The main weakness is compression.  \stackname{S9-global-r0.3} is strong for accuracy and time, but it does not maximize FLOPs reduction.  Singular methods such as \texttt{custom\_tis} and local-scope stacks at higher pruning ratios compress more aggressively, but they lose substantial accuracy.  Therefore the useful claim is not that every stack dominates every individual method; the useful claim is that \stackname{S9-global-r0.3} gives the best accuracy--time trade-off with moderate compression.

\section*{Timing caveat}
The run summarized here was produced before the pruning implementation was changed to return full method cost.  The reported time columns should therefore be read as the run's recorded prune+heal time.  The implementation has now been corrected so future custom-method matrix runs save \texttt{score\_time\_sec}, \texttt{mask\_build\_time\_sec}, \texttt{surgery\_time\_sec}, and \texttt{method\_cost\_time\_sec}.  The final thesis timing table should be regenerated with that corrected instrumentation.

\section*{Best global stack: S9-global-r0.3}
The stack selected for all global $r=0.3$ thresholds is
\begin{quote}
\texttt{custom\_entropy + custom\_class\_entropy + custom\_hrank + mean\_abs\_act + chip + custom\_reprune + custom\_tis + custom\_nisp + apoz}.
\end{quote}
The stack is stable across correlation thresholds: the membership does not change from $0.55$ to $0.90$.  Increasing the threshold mainly changes the recovered accuracy after healing, not the stack membership.

\section*{Specific comparison at the best threshold}
At $r=0.3$ and correlation threshold $0.90$, \stackname{S9-global-r0.3} gives the clearest result.  It has better accuracy gain than all listed singular methods in the comparison table, while being much faster in the recorded prune+heal time.  It does not beat \texttt{custom\_tis} on FLOPs reduction, and it is slightly below \texttt{custom\_senpis} on parameter reduction.  This is therefore an accuracy--time stack, not the maximum-compression stack.

\section*{Stacks that did not work}
The local stacks and the higher-pruning global stacks are useful negative evidence.  Local $r=0.3$ gives strong compression ($50.81\%$ FLOPs reduction) and very low time, but accuracy recovery is weak: the best local $r=0.3$ setting reaches only $+1.56$ pp over baseline.  At $r=0.5$ and $r=0.6$, local stacks compress heavily ($74.86\%$ and $83.83\%$ FLOPs reduction), but accuracy collapses.  The same pattern appears in global $r=0.6$: around $50$--$51\%$ FLOPs reduction, but a large negative healed accuracy change.  These settings should be reported as over-pruning rather than successful hybrid stacks.

\section*{Layer agreement diagnostics}
The layer agreement plots explain why the stack is large.  Several method pairs agree strongly across layers: \texttt{l1\_norm} and \texttt{custom\_l2} pass the agreement test in all layers at global $r=0.3$, threshold $0.8$; \texttt{mean\_abs\_act} and \texttt{custom\_spectral\_energy} also pass in all layers; \texttt{custom\_hrank} and \texttt{custom\_reprune} pass in about $73\%$ of layers.  Other pairs have moderate rank correlation but insufficient prune-set overlap, so they are retained as complementary rather than collapsed into one proxy.

\section*{Recommended wording for the thesis}
A precise statement supported by this run is:
\begin{quote}
For CIFAR-10/VGG16 at pruning ratio $0.3$, the nine-method global stack \stackname{S9-global-r0.3} improved healed accuracy by up to $9.96$ percentage points over the baseline while reducing FLOPs by $24.81\%$ and parameters by $51.79\%$.  Compared with singular methods, the stack achieved the best accuracy gain in the reported comparison and substantially lower recorded prune+heal time, but it did not maximize FLOPs reduction.  More aggressive local and global stacks produced larger FLOPs reductions but damaged accuracy, especially at pruning ratio $0.6$.
\end{quote}
