## Historical State Notes

Files named `STATE_RESTORE_PROMPT_*`, `SYSTEM_STATE_SNAPSHOT_*`, and dated
review summaries are historical working notes. They are useful for reconstructing
development decisions, but they are not the first place to learn how to use the
package.
